# Scientific Figure Studio：科研绘图 Skill

**先研究科学结构，再用 image2 建立视觉稿，最后忠实重建可编辑文件。**

[English](README.md) · [完整执行规范](SKILL.md) · [验收规则](references/quality-gates.md)

这是面向公众的通用 skill，适用于半导体器件截面、实验装置拆解、材料机理及科研示意图。它针对一个常见问题：图像生成稿原本精美，一转成“可编辑 SVG”，就退化成简单色块。

## 兼容性：主要支持 Codex

**默认流程几乎只面向 Codex，因为它依赖 Codex 内置的 image2 图像生成能力，以及看图、文件操作工具。** 并非每种 Codex 环境都提供这些能力；安装 skill 不会自动解锁模型。

其他 agent 平台目前不能直接照搬使用。需要准确区分：GPT Image 2 模型本身也有 API，并非 Codex 独占；但将本 skill 移植到其他平台，需要单独适配生成接口、图像检查和文件交付。本仓库没有附带独立 API 客户端或账号凭据。

## 必须执行的流程

1. **科学核对**：确认具体器件/仪器架构，核实材料顺序、界面、连接、载流子/光/热路径和标注。
2. **视觉调研**：实际查看相关优秀图例，形成构图、视角、材质、字体、箭头和留白规范；不能只读摘要就声称做过视觉调研。
3. **image2 视觉稿**：先建立并检查视觉标准，定向迭代；精美不能掩盖科学错误。
4. **忠实可编辑重建**：保留合理的渐变、浅透视、材质差异和信息层次，重建可独立选择的组件、箭头及活文字。
5. **分别验收**：科学准确、外观、文字、可编辑性、文件完整性和模型记录分别检查，有关键错误就不能宣称完成。

用户明确只要修改现有 SVG、直接绘制矢量图或先构想时，尊重该范围，不强制重新调用 image2。“Nature 级别”在这里是审美目标，不能当作期刊认可或录用保证。

## 安装与调用

可在 Codex 中要求可用的 skill 安装器执行：

```text
请安装这个仓库根目录中的 skill：
https://github.com/dongzhaohe321418-lab/scientific-figure-studio
```

手动安装：将仓库放进本机 Codex 的技能目录，文件夹名为 `scientific-figure-studio`。使用 `CODEX_HOME/skills` 的环境应遵循配置值；常见本地位置为 `~/.codex/skills`。其他版本按其实际技能发现目录安装。[英文说明](README.md)提供跨平台命令。已有同名目录时先检查，避免覆盖。

在新对话中调用：

```text
$scientific-figure-studio
制作一张双端钙钛矿/硅叠层太阳能电池截面图。
先核对具体文献架构，再以克制的科研插图风格生成 image2 视觉稿。
结构与载流子输运分为两个面板，交付保留材质层次与浅透视的 SVG。
材料层、箭头和文字应分别可编辑，并保留源文件、图注和参考依据。
```

最好提供：科研信息重点、具体架构或论文、喜欢的参考图、使用尺寸和需要编辑的内容。该 skill 没有写死某个人的电脑路径或私人材料。

## 关于“image2 最高版本”

- 优先使用**当前官方可验证、账号可用的 GPT Image 2 能力**，禁止静默降级或虚构 Pro/Max 版本。
- 当前部分 Codex 内置接口不能指定模型和质量参数，必须如实说明平台选择及版本信息是否公开，不能假装设置了 `quality=high`。
- 明确授权 API 路线时，才使用可验证的模型标识及接口支持的高质量参数；不因普通“更精美”要求就擅自改用单独计费 API。
- 每次涉及最新能力时核对官方文档，不把仓库中的日期快照当成永久保证。[详见模型策略](references/image2-execution.md)。

## 什么才算可编辑

- **完整矢量**：组件几何、边界、箭头和活文字都能编辑，提供实际源文件。
- **混合分层**：部分材质仍是位图，明确指出范围，其余内容可以编辑。
- **位图套 SVG/PPTX 外壳**：不算完整可编辑，不能隐瞒。

自动描摹不能可靠恢复科学对象和原始层次；文字转曲也不等于可直接改字。该 skill 要求按视觉稿重建并实际修改、保存、重新打开和检查。没有目标编辑器时，必须说明只做了源文件级验证。

## 自动检查与实际边界

仓库附带 SVG 结构检查、交付证据检查、默认未通过的审查模板和反例测试。Python 3.10+ 即可运行，无第三方库依赖：

```sh
python -m unittest discover -s tests -v
python scripts/audit_svg.py figure.svg --full-vector --live-text
python scripts/check_release.py review.json
```

检查脚本能发现部分假可编辑文件、缺失证据、文件被改动和未经支持的完成声明；**不能自动证明科学正确或审美优秀，也不能保证 agent 永不违反指令**。真正的科学与视觉验收仍须看图和核对来源。当前验证范围见 [VALIDATION.md](VALIDATION.md)，不虚构完整实测结果。
