# 神经网络示意图

- `neural-network.png`：正式图片，4800 × 2800，直接从 SVG 导出。
- `neural-network.svg`：可编辑原稿；文字、节点、连线及箭头均为矢量对象。
- `image2-master.png`：原始生成式视觉稿，与正式矢量稿分别保存。

## 日后继续编辑

1. 用普通浏览器打开 `svg-editor.html`，点击“打开 SVG”，选择正式 SVG。
2. 在下拉列表选择文字、节点或箭头，修改文字、颜色、位置。
3. 点击“保存 SVG”下载修改后的文件；下次重新打开该文件即可继续编辑，无需调用 image2。
4. 点击“导出 PNG”获得与当前编辑状态对应的图片。浏览器下载文件通常在“下载”文件夹，可自行移回此目录。

本次已通过本机 localhost 编辑器验证保存、重新打开、修改保留和 PNG 导出。若浏览器限制直接打开 HTML，在装有 Python 的电脑上于本文件夹运行 `python -m http.server 8770 --bind 127.0.0.1`，再打开 `http://127.0.0.1:8770/svg-editor.html`。没有依赖在线上传服务。

需要编辑复杂公式上下标时，保留 `<text>/<tspan>`，使用专业矢量软件或修改 `build_figure.py` 后重新生成。基本编辑器修改整段文字会重置该段内部的上下标排版。新增/删除网络层时应同步核对矩阵尺寸、连接关系及公式；此图原定为 4–5–5–3 网络。

`edit-test-copy` 文件是编辑测试副本，请使用 `neural-network` 文件对作为正式图稿。研究来源、图注和检查记录也保存在本目录。Inkscape、Illustrator 的实际兼容性未经本次测试。
